纸带染色：全部版本题解与 C++17 源码说明
======================================

约定
----
所有程序都只有一组数据，无测试组数 T。
纸带位置和输入区间均为 1-based 闭区间。
每次询问独立：从空白开始，只执行操作 l,l+1,...,r。
空白不作为一种颜色，不计入颜色数和平方和，但会隔开两侧颜色段。
同色不相邻的段必须分别平方，不能先把总长度相加再平方。
重复颜色版本会离散化输入颜色，真实颜色为 0 或负数也合法，内部空白另用编号 0。
代码按 n<=10^9 编写。长度平方和至多 n^2<=10^18，使用 long long。
所有 .cpp 都独立完整，可单独编译，不依赖其他源码文件。

编译示例：
g++ -std=c++17 -O2 05_twice_repeated_square.cpp -o main

版本与输入
----------
所有文件第一行都是 n m q；然后 m 行操作，q 行询问。

00_original.cpp
  原题：操作为 o x，0 表示 [1,x]，1 表示 [x,n]，每次颜色为操作编号。
  询问 l r，输出不同可见颜色数。
  时间 O((m+q)log m)，空间 O(m+q)。

01_arbitrary_unique_count.cpp
  加强①：操作为 L R，每次颜色为操作编号。
  询问 l r，输出不同可见颜色数。
  时间 O((m+q)log m)，空间 O(m+q)。

02b_prefix_repeated_count.cpp
  加强②：操作为 o x c。
  询问 l r，输出不同可见颜色数。
  时间 O((m+q)log m)，空间 O(m+q)。

02_arbitrary_repeated_count.cpp
  ①+②：操作为 L R c，颜色允许任意重复。
  询问 l r，输出不同可见颜色数。
  时间 O((m+q)log m)，空间 O(m+q)。

03b_prefix_unique_square.cpp
  加强③：操作为 o x，每次颜色为操作编号。
  询问 l r，输出连续非空白同色段长度平方和。
  时间 O((m+q)log m)，空间 O(m+q)。

03_arbitrary_unique_square.cpp
  ①+③：操作为 L R，每次颜色为操作编号。
  询问 l r，输出连续非空白同色段长度平方和。
  时间 O((m+q)log m)，空间 O(m+q)。

04_prefix_repeated_square.cpp
  ②+③：操作为 o x c，颜色允许任意重复，操作仍为前缀或后缀。
  询问 l r，输出连续非空白同色段长度平方和。
  时间 O((m+q)log m)，空间 O(m+q)。

05_twice_repeated_square.cpp
  ①+②+③，每种颜色全局最多出现两次：操作为 L R c。
  询问 l r，输出连续非空白同色段长度平方和。
  时间 O((m+q)log m)，空间 O(m+q)。
  每色最多两次是输入保证；不能直接用于某种颜色出现三次以上的数据。

06_unrestricted_square_baseline.cpp
  ①+②+③，不限制每种颜色次数：操作为 L R c，询问为 l r。
  正确的小数据基准程序，不是 m=500000 的高效解。
  时间 O(m^2 log m+q)，空间 O(m+q)。

07_spatial_unrestricted_square_baseline.cpp
  不限制每种颜色次数，并增加空间查询：操作为 L R c，询问为 l r x y。
  只执行 l..r 后，仅统计空间 [x,y] 内的各段平方和。
  跨越 x,y 的段截断到查询范围。
  正确的小数据基准程序，不是 m=500000 的高效解。
  时间 O((m^2+q)log m)，空间 O(m+q)。

一、共同性质：按询问右端点扫描
----------------------------
扫描到 r，实际执行操作 1..r，记 t(x) 为位置 x 的最后染色操作编号，未染为 0。
对于询问 [l,r]：
  t(x)>=l：最终颜色仍为 c[t(x)]；
  t(x)<l ：这个位置为空白。
因为若最后操作小于 l，则 l..r 中根本没有操作覆盖它；否则最后操作就在询问内。
这里变为空白不等于从纸带中删除这些格子，它们仍占据空间。

把询问按 r 分桶，不需要排序，也不需要回滚前 l-1 次操作。

二、维护空间段与均摊复杂度
------------------------
用 map 的 key 存段的左端点，value 存右端点和 owner。
初始一整段 [1,n] 的 owner=0。
区间赋值 [L,R]：
  split(R+1)，split(L)；
  删除中间段；
  插入新的 [L,R]。

split(x) 把包含 x 的段 [a,b] 分成 [a,x-1] 与 [x,b]，若 x 已是左端点则不操作。
x=n+1 返回 end，不能访问它。
每次赋值最多新增常数个段，所以全部操作的总新增、总删除段数为 O(m)。
这里只做区间赋值，存在确定的均摊保证；一次可能删除很多段，但整个扫描总计 O(m) 段。
每个段更新做 O(log m) 的 map/Fenwick 操作，故总计 O((m+q)log m)。

三、01：任意区间、每次独有颜色、计颜色数
-------------------------------------
令 remain[i] 是当前最后染色编号为 i 的格子总数。
颜色 i 可见当且仅当 remain[i]>0。
树状数组在 i 处维护 [remain[i]>0]，询问取 sum(r)-sum(l-1)。

split 只拆段，不改变 remain。
实际覆盖旧段时，减去它的真实长度。
remain[i] 变为 0 时，在 i 处减 1；新操作加入时，在新编号处加 1。
一个操作可能剩下几个片段，但只贡献一个颜色。
每个编号只出生、彻底消失一次。

00 与此完全同一算法，只把输入 o x 转成 [1,x] 或 [x,n]。

四、02：任意区间、允许重复颜色、计颜色数
-------------------------------------
空间仍按最后操作编号存段，不能只记录真实颜色。

对每个颜色 c，维护：
  M[c] = 当前仍有剩余格子的、颜色为 c 的最大操作编号。

颜色 c 在询问 [l,r] 可见，当且仅当 M[c]>=l。
因此每个颜色仅在 M[c] 处向树状数组贡献一个 1。

注意 M[c] 是最大“存活”编号，不是这个颜色最后一次出现的编号。
某次较新的红色操作被覆盖后，更早的红色操作可能仍在其他位置存活。

每色用递增栈保存出现编号：
  新编号入栈；
  某编号剩余长度变 0，标记死亡；
  若栈顶死亡，连续弹出失效栈顶。
栈内失效编号可暂时保留，它不影响当前最大值。
栈顶改变时，树状数组撤销旧栈顶并加入新栈顶。
每编号只入栈、出栈一次。

02b 仅转换前后缀输入，主体与 02 相同。

五、03：任意区间、每次独有颜色、连续段平方和
------------------------------------------
令 W[i] 是当前属于操作 i 的各个连续段长度平方之和。
如同一操作剩长 3、5 的两段，则 W[i]=9+25=34，不是 64。

由于每次使用独有颜色，owner 段就是最终真实颜色段。
过滤掉 owner<l 的位置后，其他段不变，故询问仍为 sum(r)-sum(l-1)。

分裂长度 a+b 的 owner=t 的旧段时：
  W[t] += a^2+b^2-(a+b)^2 = -2ab。
删除长 d 的旧段：
  W[t] -= d^2。
插入长 d 的新段：
  W[i] += d^2。
owner=0 是空白，跳过贡献。

中途 split 会暂时拆开同色段，但完整染色操作执行完后，保留的旧片段已被新颜色隔开。
只在整次染色完成后回答询问。

03b 仅转换前后缀输入，主体与 03 相同。

六、04：前后缀、颜色可重复、连续段平方和
--------------------------------------
这里不能把不同操作的平方独立相加，因为相邻同色必须合并。
改用前后缀覆盖集合的结构。

对时间询问 [l,r]：
  A = 其中所有前缀操作右端点的最大值，没有则 0；
  B = 其中所有后缀操作左端点的最小值，没有则 n+1。

这段操作覆盖的位置恰是 [1,A] 并 [B,n]。
在这个集合内，完整执行 1..r 后的颜色与只执行 l..r 相同。
集合外则是空白，不管它在完整前缀状态中是否已有颜色。

若 A+1>=B，整条纸带被覆盖，取全局平方和。
否则答案为 query(1,A).sum + query(B,n).sum。
存在中间空白时，两侧只能相加，不能合并成相邻的两段。
相邻情形 A+1=B 必须走“整条纸带”分支，保证同色跨交界合并。

空间线段树维护：
  len：实际长度；
  lc,rc：首尾颜色；
  pre,suf：首尾连续同色长度；
  sum：非空白色段平方和。

合并左右节点：
  sum = left.sum + right.sum；
  若 left.rc==right.lc 且非空白，再加 2*left.suf*right.pre。
因为 (a+b)^2-a^2-b^2=2ab。
如果左节点整段同色且交界同色，向右扩展 pre；suf 对称处理。
整段赋颜色 c：pre=suf=len，sum=len^2（空白时为 0）。

离散化使用半开区间 [0,n)：
  原 [1,x] 转 [0,x)；
  原 [x,n] 转 [x-1,n)。
叶子长度是相邻坐标之差，不能用压缩下标差。
空区间 len=0 是合并单位元；空白区间有正长度，仍会隔开两侧颜色。
时间维的 A,B 使用静态区间最值线段树查询。

七、05：任意区间、每色最多两次、连续段平方和
------------------------------------------
某颜色只出现于操作 i<j。
一个当前真实连续同色段内部，owner 至多为 i / j / i 三片。
j 是一次连续区间染色；之后的异色覆盖只会把这个色段切断，
所以同一当前色段内由 j 留下的部分一定连续。

设整个色段长度为 S，j 部分长度为 b：
  l<=i：贡献 S^2；
  i<l<=j：贡献 b^2；
  l>j：贡献 0。
将其拆成两个 Fenwick 点权：
  在 i 处加 S^2-b^2；
  在 j 处加 b^2。
单一 owner 的色段仍在它自己的编号处贡献 S^2。
询问依然是 sum(r)-sum(l-1)。

代码采用更简洁的“颜色版本”表示：
每个 map 节点是一个真实连续同色段，只存右端点与 tag。
预处理 pre[t] 为颜色 c[t] 上一次出现的操作编号，首次出现为 0。

若 pre[tag]=0，这一段完全由 tag 留下。
否则在原操作 [L[tag],R[tag]] 内的格子来自 tag，其余来自 pre[tag]。
因此无需保存三小片，只算当前段与该原区间的交长 b：
  b=max(0,min(段右端,R[tag])-max(段左端,L[tag])+1)。

tag 是表示版本，不一定是当前段内真正最大的存活 owner。
一个 tag=j 的段被分裂后，子段可能完全位于 j 区间外。
此时 b=0，公式自动只给旧操作贡献，无需更改 tag。

split 时复制 tag；删除旧段撤销贡献；插入新段 tag=i；
与左右真实颜色相同的邻居合并时，tag 取较大者，并重新计算整段贡献。
因为每色最多两次，这个表示的解码始终成立。

每个节点改动只需要至多两个 Fenwick 点修改。
每次赋值仍只新建常数个节点，所以总时间 O((m+q)log m)。

易错点：
  即使染色区间当前已经是同一种颜色，也不能跳过操作。
  颜色视觉上没变，但操作时间标签改变，会影响询问左端点过滤。
  判断是否合并使用 color[tag]，不是 tag 相等。
  本版的 split 需要撤销旧色段贡献、加入两段的新贡献。
  一定在整次赋值和同色合并完成后再回答询问。

八、06/07：无限重复颜色的正确基准程序
-----------------------------------
之前没有得到任意区间、无限重复色、平方和在原规模下的高效算法。
这里提供正确的基准实现，适合小 m、验证思路和对拍。

把询问按左端点 l 分组，每组按右端点 r 递增。
固定一个 l 后，从空白线段树开始依次执行 l,l+1,...，回答对应 r。
这样全部不同 l 的操作执行次数至多 m(m+1)/2。
06 取线段树根的 sum；07 查询给定空间 [x,y]。

代码先按 r 分桶，再按 l 收集，保证预处理 O(m+q)，不需要比较排序。
06 时间 O(m^2 log m+q)。
07 时间 O((m^2+q)log m)。
每组只保留一棵树，空间 O(m+q)。

07 不把全部查询端点加入空间离散化，空间叶子仍为 O(m)。
查询端点落在压缩叶子内部时：
  取左右叶子的颜色，并把返回副本的长度裁剪到查询范围；
  中间完整叶子正常查询；
  按真实空间顺序 mergeInfo，保留跨叶子的同色合并。
如果左右端点在同一个叶子，直接按裁剪后的长度计算即可。

// Original: operations o x; queries l r; count visible colors.
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

struct Fenwick {
    int n;
    vector<i64> tr;
    Fenwick(int size) : n(size), tr(size + 1) {}
    void add(int x, i64 v) {
        for (; x <= n; x += x & -x) tr[x] += v;
    }
    i64 sum(int x) const {
        i64 res = 0;
        for (; x; x -= x & -x) res += tr[x];
        return res;
    }
};

struct Node { int r, id; };

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;
    vector<array<int, 2>> op(m + 1);
    for (int i = 1; i <= m; i++) {
        int o, x;
        cin >> o >> x;
        op[i] = (o == 0 ? array<int, 2>{1, x} : array<int, 2>{x, n});
    }
    vector<vector<pair<int, int>>> ask(m + 1);
    for (int id = 0; id < q; id++) {
        int l, r;
        cin >> l >> r;
        ask[r].push_back({l, id});
    }
    vector<i64> ans(q);
    Fenwick bit(m);
    map<int, Node> seg;
    seg[1] = {n, 0};  // owner=0: blank

    vector<i64> remain(m + 1);
    auto split = [&](int x) {
        if (x > n) return seg.end();
        auto it = prev(seg.upper_bound(x));
        if (it->first == x) return it;
        auto [r, id] = it->second;
        it->second.r = x - 1;
        return seg.emplace(x, Node{r, id}).first;
    };

    for (int i = 1; i <= m; i++) {
        auto [L, R] = op[i];
        auto right = split(R + 1), left = split(L);
        for (auto it = left; it != right; ++it) {
            int id = it->second.id;
            if (!id) continue;
            remain[id] -= it->second.r - it->first + 1;
            if (remain[id] == 0) bit.add(id, -1);
        }
        seg.erase(left, right);
        seg.emplace(L, Node{R, i});
        remain[i] = R - L + 1;
        bit.add(i, 1);

        for (auto [l, id] : ask[i])
            ans[id] = bit.sum(i) - bit.sum(l - 1);
    }
    for (i64 x : ans) cout << x << '\n';
}

// 任意区间染色，颜色可以重复；查询操作子区间后的可见颜色数。
// 输入：n m q；m 行 L R c；q 行 l r。每个询问都从空白开始。
// 时间 O((m + q) log m)，空间 O(m + q)。C++17。
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

struct Fenwick {
    int n;
    vector<int> tr;
    Fenwick(int size) : n(size), tr(size + 1) {}
    void add(int x, int v) {
        for (; x <= n; x += x & -x) tr[x] += v;
    }

// 前缀/后缀染色，颜色可重复；询问操作区间 [l,r] 的连续色段长度平方和。
// 输入：n m q；m 行 o x c；q 行 l r。空白不计答案。
// 时间 O((m+q) log m)，空间 O(m+q)。C++17。
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

struct Info {
    i64 len = 0, pre = 0, suf = 0, sum = 0;
    int lc = 0, rc = 0;
};

Info mergeInfo(const Info &a, const Info &b) {
    if (!a.len) return b;
    if (!b.len) return a;
    Info c{a.len + b.len, a.pre, b.suf, a.sum + b.sum, a.lc, b.rc};
    if (a.rc == b.lc) {
        if (a.rc != 0) c.sum += 2 * a.suf * b.pre;
        if (a.pre == a.len) c.pre += b.pre;
        if (b.suf == b.len) c.suf += a.suf;
    }
    return c;
}

struct PaintTree {
    int n;
    vector<Info> tr;
    vector<int> tag;

    explicit PaintTree(const vector<i64> &x) : n((int)x.size() - 1) {
        int size = 1;
        while (size < n) size <<= 1;
        tr.resize(size * 2);
        tag.assign(size * 2, -1);
        auto build = [&](auto &&self, int p, int l, int r) -> void {
            tr[p].len = tr[p].pre = tr[p].suf = x[r + 1] - x[l];
            if (l == r) return;
            int mid = (l + r) / 2;
            self(self, p * 2, l, mid);
            self(self, p * 2 + 1, mid + 1, r);
        };
        build(build, 1, 0, n - 1);
    }

    void apply(int p, int c) {
        tr[p].lc = tr[p].rc = c;
        tr[p].pre = tr[p].suf = tr[p].len;
        tr[p].sum = c ? tr[p].len * tr[p].len : 0;
        tag[p] = c;
    }
    void push(int p) {
        if (tag[p] == -1) return;
        apply(p * 2, tag[p]);
        apply(p * 2 + 1, tag[p]);
        tag[p] = -1;
    }
    void assign(int p, int l, int r, int ql, int qr, int c) {
        if (ql <= l && r <= qr) return apply(p, c);
        push(p);
        int mid = (l + r) / 2;
        if (ql <= mid) assign(p * 2, l, mid, ql, qr, c);
        if (qr > mid) assign(p * 2 + 1, mid + 1, r, ql, qr, c);
        tr[p] = mergeInfo(tr[p * 2], tr[p * 2 + 1]);
    }
    Info query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tr[p];
        push(p);
        int mid = (l + r) / 2;
        if (qr <= mid) return query(p * 2, l, mid, ql, qr);
        if (ql > mid) return query(p * 2 + 1, mid + 1, r, ql, qr);
        return mergeInfo(query(p * 2, l, mid, ql, qr),
                         query(p * 2 + 1, mid + 1, r, ql, qr));
    }
    void assign(int l, int r, int c) {
        if (l <= r) assign(1, 0, n - 1, l, r, c);
    }
    Info query(int l, int r) {
        return l <= r ? query(1, 0, n - 1, l, r) : Info{};
    }
};

struct RangeEnds {
    int size = 1, inf;
    vector<pair<int, int>> tr;
    static pair<int, int> merge(pair<int, int> a, pair<int, int> b) {
        return {max(a.first, b.first), min(a.second, b.second)};
    }
    RangeEnds(int n, const vector<pair<int, int>> &v) : inf(n + 1) {
        while (size < (int)v.size()) size <<= 1;
        tr.assign(size * 2, {0, inf});
        copy(v.begin(), v.end(), tr.begin() + size);
        for (int p = size - 1; p; --p) tr[p] = merge(tr[p * 2], tr[p * 2 + 1]);
    }
    pair<int, int> query(int l, int r) const {  // 操作编号，闭区间，1-based
        pair<int, int> ans{0, inf};
        for (l += size - 1, r += size; l < r; l >>= 1, r >>= 1) {
            if (l & 1) ans = merge(ans, tr[l++]);
            if (r & 1) ans = merge(ans, tr[--r]);
        }
        return ans;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;
    struct Operation { int o, x, c, cut; };
    vector<Operation> op(m + 1);
    vector<i64> color(m + 1), values, coord{0, n};
    vector<pair<int, int>> ends;
    for (int i = 1; i <= m; ++i) {
        cin >> op[i].o >> op[i].x >> color[i];
        values.push_back(color[i]);
        coord.push_back(op[i].o == 0 ? op[i].x : op[i].x - 1);
        ends.push_back(op[i].o == 0 ? pair{op[i].x, n + 1} : pair{0, op[i].x});
    }
    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());
    sort(coord.begin(), coord.end());
    coord.erase(unique(coord.begin(), coord.end()), coord.end());
    auto index = [&](i64 x) { return int(lower_bound(coord.begin(), coord.end(), x) - coord.begin()); };
    for (int i = 1; i <= m; ++i) {
        op[i].c = int(lower_bound(values.begin(), values.end(), color[i]) - values.begin()) + 1;
        op[i].cut = index(op[i].o == 0 ? op[i].x : op[i].x - 1);
    }
    vector<vector<pair<int, int>>> ask(m + 1);
    for (int id = 0, l, r; id < q; ++id) {
        cin >> l >> r;
        ask[r].push_back({l, id});
    }

    PaintTree tree(coord);
    RangeEnds rmq(n, ends);
    vector<i64> ans(q);
    for (int r = 1; r <= m; ++r) {
        auto [o, x, c, cut] = op[r];
        if (o == 0) tree.assign(0, cut - 1, c);
        else tree.assign(cut, tree.n - 1, c);
        for (auto [l, id] : ask[r]) {
            auto [A, B] = rmq.query(l, r);
            if (A + 1 >= B) ans[id] = tree.tr[1].sum;
            else ans[id] = tree.query(0, index(A) - 1).sum
                         + tree.query(index(B - 1), tree.n - 1).sum;
        }
    }
    for (i64 x : ans) cout << x << '\n';
}

// 任意区间染色；每种颜色最多出现两次；询问操作区间内的连续色段平方和。
// 输入：n m q；m 行 L R c；q 行 l r。空白不计入答案。
// 时间 O((m + q) log m)，空间 O(m + q)。C++17。
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

struct Fenwick {
    int n;
    vector<i64> tr;
    Fenwick(int size) : n(size), tr(size + 1) {}
    void add(int x, i64 v) {
        for (; x <= n; x += x & -x) tr[x] += v;
    }
    i64 sum(int x) const {
        i64 res = 0;
        for (; x; x -= x & -x) res += tr[x];
        return res;
    }
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    i64 n;
    int m, q;
    cin >> n >> m >> q;
    vector<i64> L(m + 1), R(m + 1), raw(m + 1), values;
    for (int i = 1; i <= m; i++) {
        cin >> L[i] >> R[i] >> raw[i];
        values.push_back(raw[i]);
    }
    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());
    vector<int> color(m + 1), pre(m + 1), last(values.size() + 1);
    for (int i = 1; i <= m; i++) {
        color[i] = lower_bound(values.begin(), values.end(), raw[i]) - values.begin() + 1;
        pre[i] = last[color[i]];
        last[color[i]] = i;
    }

    vector<vector<pair<int, int>>> ask(m + 1);
    for (int id = 0; id < q; id++) {
        int l, r;
        cin >> l >> r;
        ask[r].push_back({l, id});
    }
    vector<i64> ans(q);
    Fenwick bit(m);

    // 每个节点是一个真实同色段；tag 表示它采用的颜色版本。
    // tag 的第二次染色范围内属于 tag，范围外属于 pre[tag]。
    struct Node { i64 r; int tag; };
    map<i64, Node> seg;
    seg[1] = {n, 0};

    auto change = [&](auto it, int sign) {
        auto [l, node] = *it;
        auto [r, t] = node;
        if (!t) return; // 空白
        i64 len = r - l + 1;
        if (!pre[t]) {
            bit.add(t, sign * len * len);
        } else {
            i64 b = max(0LL, min(r, R[t]) - max(l, L[t]) + 1);
            bit.add(pre[t], sign * (len * len - b * b));
            bit.add(t, sign * b * b);
        }
    };

    auto split = [&](i64 x) {
        if (x > n) return seg.end();
        auto it = prev(seg.upper_bound(x));
        if (it->first == x) return it;
        Node node = it->second;
        change(it, -1);
        it->second.r = x - 1;
        change(it, 1);
        auto rt = seg.emplace(x, node).first;
        change(rt, 1);
        return rt;
    };

    auto join = [&](auto a, auto b) {
        change(a, -1);
        change(b, -1);
        a->second.r = b->second.r;
        a->second.tag = max(a->second.tag, b->second.tag);
        seg.erase(b);
        change(a, 1);
        return a;
    };

    for (int i = 1; i <= m; i++) {
        auto rt = split(R[i] + 1);
        auto it = split(L[i]);
        while (it != rt) {
            change(it, -1);
            it = seg.erase(it);
        }
        it = seg.emplace(L[i], Node{R[i], i}).first;
        change(it, 1);

        if (it != seg.begin()) {
            auto lt = prev(it);
            if (color[lt->second.tag] == color[i]) it = join(lt, it);
        }
        rt = next(it);
        if (rt != seg.end() && color[rt->second.tag] == color[i]) join(it, rt);

        for (auto [l, id] : ask[i]) ans[id] = bit.sum(i) - bit.sum(l - 1);
    }
    for (i64 x : ans) cout << x << '\n';
}

    if (a.rc == b.lc) {
        if (a.rc != 0) c.sum += 2 * a.suf * b.pre;
        if (a.pre == a.len) c.pre += b.pre;
        if (b.suf == b.len) c.suf += a.suf;
    }
    return c;
}

struct PaintTree {
    int n;
    vector<Info> tr;
    vector<int> tag;

    explicit PaintTree(const vector<i64> &x) : n((int)x.size() - 1) {
        int size = 1;
        while (size < n) size <<= 1;
        tr.resize(size * 2);
        tag.assign(size * 2, -1);
        auto build = [&](auto &&self, int p, int l, int r) -> void {
            tr[p].len = tr[p].pre = tr[p].suf = x[r + 1] - x[l];
            if (l == r) return;
            int mid = (l + r) / 2;
            self(self, p * 2, l, mid);
            self(self, p * 2 + 1, mid + 1, r);
        };
        build(build, 1, 0, n - 1);
    }

    void apply(int p, int c) {
        tr[p].lc = tr[p].rc = c;
        tr[p].pre = tr[p].suf = tr[p].len;
        tr[p].sum = c ? tr[p].len * tr[p].len : 0;
        tag[p] = c;
    }
    void push(int p) {
        if (tag[p] == -1) return;
        apply(p * 2, tag[p]);
        apply(p * 2 + 1, tag[p]);
        tag[p] = -1;
    }
    void assign(int p, int l, int r, int ql, int qr, int c) {
        if (ql <= l && r <= qr) return apply(p, c);
        push(p);
        int mid = (l + r) / 2;
        if (ql <= mid) assign(p * 2, l, mid, ql, qr, c);
        if (qr > mid) assign(p * 2 + 1, mid + 1, r, ql, qr, c);
        tr[p] = mergeInfo(tr[p * 2], tr[p * 2 + 1]);
    }
    Info query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tr[p];
        push(p);
        int mid = (l + r) / 2;
        if (qr <= mid) return query(p * 2, l, mid, ql, qr);
        if (ql > mid) return query(p * 2 + 1, mid + 1, r, ql, qr);
        return mergeInfo(query(p * 2, l, mid, ql, qr),
                         query(p * 2 + 1, mid + 1, r, ql, qr));
    }
    void assign(int l, int r, int c) {
        if (l <= r) assign(1, 0, n - 1, l, r, c);
    }
    Info query(int l, int r) {
        return l <= r ? query(1, 0, n - 1, l, r) : Info{};
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;
    struct Operation { int L, R, c, a, b; };
    vector<Operation> op(m + 1);
    vector<i64> raw(m + 1), values, coord{0, n};
    for (int i = 1; i <= m; i++) {
        cin >> op[i].L >> op[i].R >> raw[i];
        values.push_back(raw[i]);
        coord.push_back(op[i].L - 1);
        coord.push_back(op[i].R);
    }
    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());
    sort(coord.begin(), coord.end());
    coord.erase(unique(coord.begin(), coord.end()), coord.end());
    auto index = [&](i64 x) {
        return int(lower_bound(coord.begin(), coord.end(), x) - coord.begin());
    };
    for (int i = 1; i <= m; i++) {
        op[i].c = int(lower_bound(values.begin(), values.end(), raw[i]) - values.begin()) + 1;
        op[i].a = index(op[i].L - 1);
        op[i].b = index(op[i].R) - 1;
    }

    struct Query { int l, r, x, y, id; };
    vector<vector<Query>> byRight(m + 1), byLeft(m + 1);
    for (int id = 0; id < q; id++) {
        int l, r, x = 1, y = n;
        cin >> l >> r;
        byRight[r].push_back({l, r, x, y, id});
    }
    // Counting-sort the queries by r, then group by l.
    for (int r = 1; r <= m; r++)
        for (auto query : byRight[r]) byLeft[query.l].push_back(query);

            }
            ans[query.id] = tree.tr[1].sum;
        }
    }
    for (i64 x : ans) cout << x << '\n';
}

// Unrestricted repeated colors + time and spatial query intervals.
// BASELINE ONLY: O((m^2+q) log m) time, O(m+q) space; not for m=500000.
// Input: n m q; m lines L R c; q lines l r x y.
#include <bits/stdc++.h>
using namespace std;
using i64 = long long;

struct Info {
    i64 len = 0, pre = 0, suf = 0, sum = 0;
    int lc = 0, rc = 0;
};

Info mergeInfo(const Info &a, const Info &b) {
    if (!a.len) return b;
    if (!b.len) return a;
    Info c{a.len + b.len, a.pre, b.suf, a.sum + b.sum, a.lc, b.rc};
    if (a.rc == b.lc) {
        if (a.rc != 0) c.sum += 2 * a.suf * b.pre;
        if (a.pre == a.len) c.pre += b.pre;
        if (b.suf == b.len) c.suf += a.suf;
    }
    return c;
}

struct PaintTree {
    int n;
    vector<Info> tr;
    vector<int> tag;

    explicit PaintTree(const vector<i64> &x) : n((int)x.size() - 1) {
        int size = 1;
        while (size < n) size <<= 1;
        tr.resize(size * 2);
        tag.assign(size * 2, -1);
        auto build = [&](auto &&self, int p, int l, int r) -> void {
            tr[p].len = tr[p].pre = tr[p].suf = x[r + 1] - x[l];
            if (l == r) return;
            int mid = (l + r) / 2;
            self(self, p * 2, l, mid);
            self(self, p * 2 + 1, mid + 1, r);
        };
        build(build, 1, 0, n - 1);
    }

    void apply(int p, int c) {
        tr[p].lc = tr[p].rc = c;
        tr[p].pre = tr[p].suf = tr[p].len;
        tr[p].sum = c ? tr[p].len * tr[p].len : 0;
        tag[p] = c;
    }
    void push(int p) {
        if (tag[p] == -1) return;
        apply(p * 2, tag[p]);
        apply(p * 2 + 1, tag[p]);
        tag[p] = -1;
    }
    void assign(int p, int l, int r, int ql, int qr, int c) {
        if (ql <= l && r <= qr) return apply(p, c);
        push(p);
        int mid = (l + r) / 2;
        if (ql <= mid) assign(p * 2, l, mid, ql, qr, c);
        if (qr > mid) assign(p * 2 + 1, mid + 1, r, ql, qr, c);
        tr[p] = mergeInfo(tr[p * 2], tr[p * 2 + 1]);
    }
    Info query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return tr[p];
        push(p);
        int mid = (l + r) / 2;
        if (qr <= mid) return query(p * 2, l, mid, ql, qr);
        if (ql > mid) return query(p * 2 + 1, mid + 1, r, ql, qr);
        return mergeInfo(query(p * 2, l, mid, ql, qr),
                         query(p * 2 + 1, mid + 1, r, ql, qr));
    }
    void assign(int l, int r, int c) {
        if (l <= r) assign(1, 0, n - 1, l, r, c);
    }
    Info query(int l, int r) {
        return l <= r ? query(1, 0, n - 1, l, r) : Info{};
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m, q;
    cin >> n >> m >> q;
    struct Operation { int L, R, c, a, b; };
    vector<Operation> op(m + 1);
    vector<i64> raw(m + 1), values, coord{0, n};
    for (int i = 1; i <= m; i++) {
        cin >> op[i].L >> op[i].R >> raw[i];
        values.push_back(raw[i]);
        coord.push_back(op[i].L - 1);
        coord.push_back(op[i].R);
    }
    sort(values.begin(), values.end());
    values.erase(unique(values.begin(), values.end()), values.end());
    sort(coord.begin(), coord.end());
    coord.erase(unique(coord.begin(), coord.end()), coord.end());
    auto index = [&](i64 x) {
        return int(lower_bound(coord.begin(), coord.end(), x) - coord.begin());
    };
    for (int i = 1; i <= m; i++) {
        op[i].c = int(lower_bound(values.begin(), values.end(), raw[i]) - values.begin()) + 1;
        op[i].a = index(op[i].L - 1);
        op[i].b = index(op[i].R) - 1;
    }

    struct Query { int l, r, x, y, id; };
    vector<vector<Query>> byRight(m + 1), byLeft(m + 1);
    for (int id = 0; id < q; id++) {
        int l, r, x = 1, y = n;
        cin >> l >> r >> x >> y;
        byRight[r].push_back({l, r, x, y, id});
    }
    // Counting-sort the queries by r, then group by l.
    for (int r = 1; r <= m; r++)
        for (auto query : byRight[r]) byLeft[query.l].push_back(query);
    vector<vector<Query>>().swap(byRight);

    vector<i64> ans(q);
    for (int l = 1; l <= m; l++) {
        if (byLeft[l].empty()) continue;
        PaintTree tree(coord);  // Start from a blank tape for this l.
        int r = l - 1;
        auto cropLeaf = [&](int p, i64 len) {
            Info z = tree.query(p, p);
            z.len = z.pre = z.suf = len;
            z.sum = z.lc ? len * len : 0;
            return z;
        };
        auto querySpace = [&](int x, int y) {
            i64 left = x - 1, right = y;  // Physical half-open interval.
            int a = int(upper_bound(coord.begin(), coord.end(), left) - coord.begin()) - 1;
            int b = int(lower_bound(coord.begin(), coord.end(), right) - coord.begin()) - 1;
            if (a == b) return cropLeaf(a, right - left).sum;
            Info first = cropLeaf(a, coord[a + 1] - left);
            Info last = cropLeaf(b, right - coord[b]);
            return mergeInfo(mergeInfo(first, tree.query(a + 1, b - 1)), last).sum;
        };
        for (auto query : byLeft[l]) {
            while (r < query.r) {
                ++r;
                tree.assign(op[r].a, op[r].b, op[r].c);
            }
            ans[query.id] = querySpace(query.x, query.y);
        }
    }
    for (i64 x : ans) cout << x << '\n';
}
